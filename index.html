    Paytm · Backend on AWS

    A faster, safer backend for IoT payment devices.

    The problem. Large fleets of IoT payment devices needed secure registration, transaction notifications and fast authentication, without hammering the database on every request.

    • Built and optimized REST APIs for device onboarding on AWS, with secure registration using X.509 certificates.
    • Built APIs for transaction notifications and transaction-summary retrieval.
    • Added a Redis cache layer: about 1M fewer database hits a day, and auth-ID lookup latency down from 200 ms to ~80 ms.
    • Integrated AWS IoT Device Defender to detect abnormal behaviour and unauthorized access across the fleet.

    ~60% faster auth-ID lookups and a much lighter database.

    Microsoft · AI agent

    A Claude-based agent that writes the sprint report.

    The problem. Putting together a sprint report from Azure DevOps took 30 to 60 minutes of manual work, and risks such as carry-overs and stuck PRs were easy to miss.

    • Built a Claude-based agent that works from live Azure DevOps data and produces the report end to end.
    • Automatically flags workflow risks: carry-overs, PBI bottlenecks and PR bottlenecks.
    • Ships 3 role-specific report modes from the same data, now used by multiple teams.

    ~95% less time: 30–60 min down to about 90 seconds.

    05 · How I work

    Four habits behind those numbers.

    01

    Design before code

    I write the design doc first. My platform migration design had teams in China and the US agreeing on it before anything moved.

    02

    Performance is a feature

    Find the hot path, then fix it. One Redis layer took auth-ID lookups from 200 ms to ~80 ms and took a million queries a day off the database.

    03

    Secure by default

    X.509 device auth at Paytm, secure credential storage at Samsung, and automated security checks at Microsoft. Security belongs in the design.

    04

    Automate the toil

    If I do something twice, I script it. If a whole team does it every week, I build a tool or an agent for it.
